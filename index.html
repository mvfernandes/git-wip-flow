Fluxo Git: Checkpoints Imutáveis e Branching com Sufixo WIP

Guia definitivo focado em segurança absoluta contra perda de dados, revisão visual na IDE e histórico cirúrgico para PRs. Sem --force, sem acúmulo de lixo.

📅 Convenção .wip-{data}

Qualquer dev ou CI reconhece que feature.wip-2026-09-25 é backup, não release.

🗑 Limpeza Contínua

Branches antigas apagadas diariamente local e remoto. Sempre 1 WIP ativa.

🔒 Snapshot Único

Zero poluição. Repositório nunca acumula branches órfãs.

📅 DIA 1 — Inicial

Criar branch: feature.wip-2026-09-24
Desenvolver e testar
Commit e Push (Backup nuvem)
→

📅 DIA 2 — Continuação

Criar nova branch da dev: .wip-2026-09-25
git merge --squash --no-commit wip-24
→ traz pra Staged
Desenvolver na IDE
Push novo backup + 🗑 apagar wip-24
→

🏁 ENTREGA FINAL — PR

Criar branch definitiva: feature-conciliacao
git merge --squash --no-commit wip-25
Revisão visual linha a linha
Commit único + PR + 🗑 apagar último WIP

Passo a Passo Prático

Passo 1: Snapshot do Dia 1

bash
# 1. Cria e acessa a branch com sufixo do dia
git checkout -b feature-conciliacao.wip-2026-09-24

# 2. Adiciona tudo e commita
git add .
git commit -m "wip: conciliacao inicial com paineis e filtros"

# 3. Envia para o remote (backup seguro garantido!)
git push origin feature-conciliacao.wip-2026-09-24

Passo 2: Novo Dia — O pulo do gato

bash — método definitivo
# 1. Atualiza sua development local
git checkout development
git pull origin development

# 2. Cria a nova branch para o trabalho de hoje
git checkout -b feature-conciliacao.wip-2026-09-25

# 3. O PULO DO GATO: importa o snapshot anterior direto para Staged
git merge --squash --no-commit feature-conciliacao.wip-2026-09-24

# 4. Conferência obrigatória
git diff --cached --stat
# deve listar só arquivos da sua feature!

⚠ Por que não usar checkout -- . ?

Ele copia a árvore inteira da WIP antiga por cima da development nova. Arquivos que outras pessoas alteraram voltam para versão antiga sem aviso. Use sempre merge --squash --no-commit que faz merge de 3 vias e mostra conflito.

💡 Se a WIP anterior só existe no remoto

git fetch origin
git merge --squash --no-commit origin/feature-conciliacao.wip-2026-09-24

Passo 3: Salvar hoje e apagar ontem

bash
git add .
git commit -m "wip: responsividade e botoes delphi ajustados"
git push origin feature-conciliacao.wip-2026-09-25

# LIMPEZA DIÁRIA - apaga no remoto primeiro (mais seguro)
git push origin --delete feature-conciliacao.wip-2026-09-24
git branch -D feature-conciliacao.wip-2026-09-24

Passo 4: Branch oficial para PR

bash
git checkout development
git pull origin development

git checkout -b feature-conciliacao
git merge --squash --no-commit feature-conciliacao.wip-2026-09-25

# Revisão visual final no Source Control da IDE!
git commit -m "feat(conciliacao): implementa tela de conciliacao bancaria paritaria ao delphi"
git push origin feature-conciliacao

# LIMPEZA FINAL
git push origin --delete feature-conciliacao.wip-2026-09-25
git branch -D feature-conciliacao.wip-2026-09-25

Resumo em 3 Comandos Diários

1 — Iniciar Dia

git checkout -b feature.wip-HOJE \
&& git merge --squash --no-commit \
   feature.wip-ONTEM

2 — Encerrar Dia

git add . \
&& git commit -m "wip: ..." \
&& git push origin feature.wip-HOJE

3 — Eliminar Ontem

git push origin --delete \
   feature.wip-ONTEM \
&& git branch -D feature.wip-ONTEM
